7 배포 방법 (터미널 불필요)
  1. GitHub 저장소 nasong27-oss/zero_to_product · main 브랜치 확인
  2. vercel.com 접속 → Add New Project → 저장소 선택 → Deploy
  3. Vercel 프로젝트 → Storage 탭 → Create Database → Neon Postgres 생성
  4. Connect to Project 클릭 → 환경변수 자동 설정 완료
  5. Deployments 탭 → 최근 배포 → Redeploy → 빌드 완료 후 접속 가능
